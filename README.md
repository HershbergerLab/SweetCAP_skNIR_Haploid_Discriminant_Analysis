# SweetCAP_skNIR_Haploid_Discriminant_Analysis
**Description of the data and file structure**
Rapid and accurate haploid kernel identification remains a major bottleneck in maize doubled haploid production, particularly in sweet corn germplasm where the widely used R1-nj kernel color marker is frequently suppressed, resulting in unreliable visual haploid sorting. To address this challenge, we evaluated an automated single-kernel near-infrared (skNIR) spectroscopy-based sorting system across 12 induction populations derived from two field corn and two sweet corn donor backgrounds and four high-oil haploid inducer lines. We compared two skNIR-based haploid sorting approaches: predicted oil content-based methods and spectra-based multivariate classification methods.

**Files and variables**
File: Data_skNIR_Manuscript.csv

**Description: **

**Variables**
Index: Unique identifier for each kernel sample.
source: Data source; all samples were collected at the Iowa State University (ISU) location.
population: Population ID (1–12) representing induction crosses generated by crossing four donor (female) parents with four inducer (male) parents.
plate: ID of the 24-well microtiter plate used to track kernel samples.
vis.score: Visual classification by experienced technical staff. Values: 1 = haploid, 4 = hybrid, 5 = defective.
dna.score.final: True kernel class determined using genomic DNA (gDNA) markers. Values: 1 = haploid, 4 = hybrid. These labels served as the reference standard for evaluating the accuracy of visual, oil-based, and multivariate classification methods. A value of 5 indicates kernels visually classified as defective (same as vis.score).
Donor: Female parent.
Inducer: Male parent.
pred.oil: Predicted kernel oil content (%) from the single-kernel near-infrared (skNIR) spectroscopy sorter, used to evaluate two oil-based haploid classification methods.
nmr.oil: Kernel oil content (%) measured by Nuclear Magnetic Resonance (NMR) spectroscopy to validate the predicted oil content.
X940 - X1640: Absorbance values at wavelengths from 940 to 1640 nm. These spectral variables were used to evaluate three supervised multivariate methods for haploid classification.

**Missing data**
Missing values are represented as NA

**File: skNIR_RScript1.R**
Description: RScript1 contains the R code used to analyze and evaluate two oil-based haploid sorting methods and three multivariate classification methods. The script also generates the Figure 3.

**File: skNIR_RScript2.R**
Description: RScript2 contains the R code for all remaining analyses conducted in this study and generates all other figures.

Code/software
The analyses were conducted using R v4.4.0 (R Core Team, 2024). The CSV data file was uploaded in R for conducting further analyses. The required R libraries are specified and loaded within the scripts and corresponding packages must be installed before running the scripts.
